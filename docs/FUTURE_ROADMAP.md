# EterPay — Future Roadmap (P1, P2, P3 Platform Expansion)

> **Strategic Post-Hackathon Evolution**

---

## Phase 1: High-Value Commercial Additions (P1)
* **Smart Invoicing Module:** Full implementation of PayPal Invoicing v2 API with PDF receipt generation.
* **Peer-to-Peer Payment Links:** Universal hosted payment links and dynamic QR code generation.
* **Merchant Sales Dashboard:** Dedicated business analytics view with revenue trend comparisons.
* **Proactive Rate Alerts:** Automated notifications when favorable currency conversion windows occur.

---

## Phase 2: Extended Ecosystem Capabilities (P2)
* **Subscription Management:** Integration with PayPal Subscriptions v1 API with automated cancellation reminders.
* **Dispute & Protection Console:** Automated evidence compilation and dispute tracking using PayPal Disputes v1.
* **Advanced Merchant Reporting:** Multi-currency payment reconciliation and automated tax estimation.

---

## Phase 3: Long-Term Enterprise Platform (P3)
* **Multi-Provider Payment Routing:** Dynamic failover routing between PayPal and domestic clearing networks.
* **Multi-Currency Virtual Accounts:** Partnership with licensed banking-as-a-service providers for virtual IBANs.
* **Automated Batch Payouts:** Global contractor disbursements using PayPal Payouts v1 API.
