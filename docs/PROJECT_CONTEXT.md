# Project Context — EterPay

> **Tagline:** Your Money. Everywhere. Intelligently Connected.  
> **Target Event:** EterPay Global Financial Platform  
> **Deadline:** November 12, 2026, 12:00 PM PST  
> **License:** MIT Open Source License

## 1. Vision & Core Mission
EterPay is a conversational, AI-orchestrated multi-currency financial platform designed to eliminate friction, hidden markups, and complexity in international spending and travel budgeting. Built on the PayPal Developer Platform and AG Grid, EterPay provides a single intelligent cockpit where users can plan trips, analyze exchange-rate volatility, discover travel accessories, and execute verified sandbox payments.

## 2. Non-Goals & Boundaries
* NOT an unregulated retail forex trading platform.
* NOT an issuer of synthetic tokens or private cryptocurrencies.
* NOT an unauthorized custodian of fiat balances.
* ALL currency investments are strictly modeled as educational simulations.
